# 📦 Inventário de Itens

Este projeto é um sistema de gerenciamento de inventário de produtos desenvolvido em **Java** utilizando **Swing** para a interface gráfica. A aplicação permite o controle de itens no estoque, incluindo **pesquisa**, **inserção**, **atualização** e **exclusão** de produtos. Ideal para quem busca uma solução simples e eficiente para gerenciar produtos em estoque.

---

## 🚀 Funcionalidades

- ✅ **Pesquisa de produtos** por nome ou código  
- ✅ **Exibição de dados** como código, nome, preço e estoque dos itens  
- ✅ **Inserção de novos produtos** no inventário  
- ✅ **Atualização de dados** como preço e estoque dos produtos existentes  
- ✅ **Exclusão de produtos** a partir do código informado  
- ✅ **Interação simples e intuitiva** através de botões na interface gráfica

---

## 🧠 Regras de Validação

### 🔒 Campo de pesquisa:
A pesquisa pode ser feita por nome ou código do produto. O sistema irá exibir os produtos que correspondem ao termo inserido.

---

### 🔢 Inserção de produtos:
Os dados inseridos, como preço e estoque, devem ser valores numéricos válidos. Se os dados estiverem fora do formato esperado, o sistema alertará o usuário.

---

## 🛠️ Tecnologias Utilizadas

- **Java 17+**  
- **Swing** para a criação da interface gráfica  
- **JDBC** para interação com o banco de dados (MySQL/SQLite)  
- **MySQL/SQLite** para armazenamento dos dados (configurável conforme a escolha do usuário)
